# 👗 VOGUEVA — Interactive Fashion & Model Gallery

**VOGUEVA** is a modern fashion gallery website built using **React and Vite**. It showcases stylish model photography and fashion visuals through an interactive photo-card layout with smooth animations and a full-screen image viewer.

---

## 🖥️ Project Overview

VOGUEVA provides a premium fashion browsing experience with an elegant dark theme, interactive photo cards, and responsive design.

### Highlights:
- ✔ Interactive fashion and model gallery
- ✔ Stylish tilted photo-card layout
- ✔ Full-screen image viewer
- ✔ Smooth animations and hover effects
- ✔ Keyboard navigation between images
- ✔ Responsive design for all devices

---

## 🚀 Features

### 👗 Fashion Gallery
- Displays model photographs in a stylish card layout.
- Supports custom photos, titles, and captions.

### 🔍 Image Viewer
- Opens photographs in full-size view.
- Navigate using arrow buttons or keyboard keys.
- Press Escape to close the viewer.

### 🎨 User Interface
- Modern dark theme with elegant typography.
- Smooth animations and interactive effects.
- Responsive layout for desktop and mobile.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Tools:** VS Code, Git, GitHub

---

## ▶️ How to Run

**Requirements:** Node.js 18 or newer.

1. Open the project folder in VS Code.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown in the terminal.

---

## 📸 Add Your Own Photos

1. Add images to `public/images/`.
2. Update the photo details in `src/photos.js`.
3. Save the changes and refresh the website.
